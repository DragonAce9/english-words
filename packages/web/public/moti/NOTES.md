# Moti art pack — NOTES

**Boards:** 512×512 storyboard frames, every frame kept. Playback is 4× the 12 fps source (21 ms, 145 frames, about 3 s). `*-still.webp` is frame 1 for `prefers-reduced-motion`.

## Clips

| Clip | File | Plays when |
| --- | --- | --- |
| idle | `idle.webp` | calm life |
| yawn, stretch, sneeze, shy, drink, sleep, wave | same names | one random gesture between breaths, not a fixed list |
| correct, wrong, newword, exam-passed, test-passed | same names | kept for those moments, not played in the home loop |
| coins | `coins.webp` | a happy gesture, and the coins reaction |
| sad | `sad.webp` | suffering, or a low hunger / mood bar |
| feed | `feed.webp` | feed action |
| play | `play.webp` | play action |
| cold | `cold.webp` | shivering clip; not the cryo portrait |
| unfreeze | `unfreeze.webp` | rescue from cryo (second take) |

Between gestures he keeps breathing. A happy Moti picks a gesture more often. The next clip is drawn underneath the current one and shown only after it has loaded.
