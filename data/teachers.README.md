# Преподаватели

Профили живут в Postgres, таблица `teachers`. Колонка `language` — язык, который учит пользователь. Старые строки — `en`. Один и тот же Telegram может быть в двух языках: уникальность по паре `(language, username)`. Лента показывает только язык текущего пользователя (`users.language`). Добавляет и удаляет профили администратор — Telegram-аккаунт из `SUPPORT_TELEGRAM_USERNAME` (сейчас `@YOUR_SUPPORT_USERNAME`). Фото берётся из профиля Telegram преподавателя: бот запрашивает его по username. Если человек ещё не открывал бота, фото появится после `/start` и кнопки «Обновить фото».

[`teachers.json`](teachers.json) — только первая загрузка английских профилей, если таблица ещё пустая. После этого правки в файле сами в ленту не попадают. Французских профилей файл не создаёт.
